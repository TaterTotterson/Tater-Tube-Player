# Trailer notes

`tater-tube-player-store-trailer-v1.mp4` is the first store-page cut. It uses
the current Linux build screen-recorded on a Steam Deck at 1920 x 1080 and
30 fps. The Deck navigates the real demo-mode UI during the capture; the final
section is actual moving video playing inside Tater Tube Player. Short
crossfades join the clean takes. This is not a slideshow or simulated UI.

The silent AAC stereo track is intentional: the product is understandable from
its UI alone, and no music rights need to be cleared for this first cut.

The playback excerpt is the Pexels video “Stunning abstract animation of galaxy
and stars in deep space” by Borys Zaitsev:
