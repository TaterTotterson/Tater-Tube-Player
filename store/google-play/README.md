# Google Play release assets

This directory contains the rights-safe submission materials for the native
Google TV and Android TV edition of Tater Tube Player.

## Graphics

- `graphics/play-store-icon-512.png` — 512 x 512 Play Store icon, RGBA PNG
- `graphics/feature-graphic-1024x500.png` — 1024 x 500 feature graphic, RGB PNG
- `graphics/android-tv-banner-1280x720.png` — 1280 x 720 Play Console TV banner, RGB PNG
- `screenshots/` — final 1920 x 1080 captures from the current physical-TV test build

The 320 x 180 launcher banner embedded in the application is separate from the
1280 x 720 Android TV banner uploaded in Play Console.

## Final screenshot set

The captures in `screenshots/` come from **Try Demo** mode on the physical TCL
test television, with no device frame or extra marketing copy:

1. Home
2. Library
3. All Movies
4. Television shows
5. Tube TV guide
6. Discover
7. Tater Picks
8. Title details and playback choices

Do not use screenshots from a personal server or substitute Apple TV or Steam
captures. Recapture this set from the exact signed internal-test build if its
rendering differs before submission.

See `ASSET_PROVENANCE.md`, `REVIEW_NOTES.md`, and
`PLAY_CONSOLE_CHECKLIST.md` before uploading.
