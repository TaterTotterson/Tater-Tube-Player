# Google Play reviewer notes

Tater Tube Player is a couch-friendly Google TV and Android TV client for a
user-operated Tater Tube Server. The application does not include movies,
television programs, or public live channels.

No account, username, password, or server is required for review:

1. Launch Tater Tube Player.
2. Select **Try Demo** on the pairing screen.
3. Demo mode uses fictional local catalog data and does not connect to a Tater
   Tube Server.
4. Select a title and choose Play or Resume to test the bundled rights-safe
   H.264/AAC demo reel.
5. The remote can seek the demo, open the Tater playback overlay, and return to
   the catalog. Tube TV demo playback is intentionally locked to a live-style
   timeline.

Full personal-library, Discover, Tater Picks, and scheduled Tube TV playback
require a separately installed Tater Tube Server configured by the user. These
features use the same interface shown in demo mode, but no server or media is
bundled with the application.
